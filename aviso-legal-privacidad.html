Finalidad del sitio web

Este sitio web tiene carácter informativo y tiene como finalidad presentar los servicios de preparación física para opositores a Guardia Civil, Policía Nacional y Policía Local.

La información publicada en esta web no constituye una garantía de superación de pruebas físicas ni de aprobación de procesos selectivos. La preparación física dependerá de la situación inicial, constancia, evolución y circunstancias individuales de cada persona.

Propiedad intelectual

Los contenidos de este sitio web, incluyendo textos, diseño, imágenes, logotipo, estructura visual y elementos gráficos, pertenecen a la titular de la web o se utilizan con las autorizaciones correspondientes.

Queda prohibida su reproducción, distribución o modificación sin autorización expresa.

Protección de datos personales

Este sitio web no incluye formularios de contacto, no dispone de base de datos propia y no recopila datos personales directamente mediante la navegación.

La vía principal de contacto es WhatsApp. Si el usuario decide contactar voluntariamente a través de WhatsApp, los datos que facilite serán tratados únicamente para responder a su consulta y ofrecer información sobre los servicios solicitados.

No se enviarán comunicaciones publicitarias masivas ni newsletters.
No se cederán datos personales a terceros, salvo obligación legal.
No se utilizarán los datos para finalidades distintas a la atención de la consulta o la relación profesional que pudiera derivarse.

Uso de WhatsApp

Al utilizar el enlace de WhatsApp, el usuario abandona este sitio web y pasa a utilizar una plataforma externa. El tratamiento de datos realizado por WhatsApp se rige por sus propias condiciones y políticas de privacidad.

Conservación de los datos

Los datos facilitados voluntariamente durante la comunicación podrán conservarse durante el tiempo necesario para atender la consulta, gestionar la posible relación profesional o cumplir obligaciones legales aplicables.

Derechos de los usuarios

El usuario puede solicitar el acceso, rectificación, supresión, limitación u oposición respecto a sus datos personales escribiendo a la titular mediante los canales de contacto indicados en esta página.

Este sitio web puede contener enlaces a páginas externas, como WhatsApp, organismos oficiales o normativa relacionada con pruebas físicas.

La titular no se responsabiliza del contenido, funcionamiento o políticas de privacidad de sitios web de terceros.

Responsabilidad

La titular procura que la información publicada sea clara y actualizada, pero no garantiza la ausencia total de errores ni que la información oficial sobre convocatorias o pruebas físicas esté siempre actualizada.
